# Smart Assistant and Guidance for Elders (SAGE)

This project is developing an autonomous mobile assistant, to
support elderly users under a home environment.

## Abstract

Our solution of Camera + Audio Beamforming + Radar to traverse the
home is made in mind of a more cost effective solution instead of
relying on LiDAR and multiple Cameras.

Here are the features planning to be added
 - [ ] Traverse home via SLAM
 - [ ] Respond to voice commands
 - [ ] Provide Emergency Support/Help


This project is for *EECS 159A and 159B: Senior Design Project (Capstone)*, for 2026-2027 School Year at UCI


## Dependencies
 - ROS2 Lyrical

## Build

In order to build the colcon project, go to the `ros` directory to do so:
```sh
$ cd ros/
$ colcon build --symlink-install
```
